## 시작하기

### 1. PC 리시버 실행

1. [Releases](../../releases/latest)에서 `TaptrolReceiver.exe`를 받습니다. **파이썬 설치 불필요.**
2. 실행하면 **Windows 방화벽 팝업**이 뜹니다 — **허용**하세요.
   8765/TCP와 8766/UDP를 사용하며, 여기서 차단하면 워치가 PC를 끝내 찾지 못합니다.
3. 창에 PC 이름·IP와 **16자리 확인 코드**(`7A4F-D210-B39C-82E1`)가 표시됩니다.

> ⚠️ 코드 서명 전까지 Windows SmartScreen이 "알 수 없는 게시자" 경고를 띄웁니다.
> `추가 정보 → 실행`으로 진행하세요. 아래 방법으로 파일 무결성을 먼저 확인하실 수 있습니다.

<details>
<summary><b>다운로드 파일 검증하기 (SHA-256)</b></summary>

릴리스마다 각 파일 옆에 같은 이름의 `.sha256` 파일이 함께 올라갑니다.
값을 여기 적어두지 않는 이유는 릴리스마다 달라지기 때문입니다 — 받으신 버전의
`.sha256`을 같이 내려받아 대조하세요.

PowerShell에서:

```powershell
Get-FileHash .\TaptrolReceiver.exe -Algorithm SHA256 | Select-Object -ExpandProperty Hash
Get-Content .\TaptrolReceiver.exe.sha256
```

두 줄에 찍힌 64자리 값이 같으면 파일이 온전한 것입니다. 다르면 실행하지 마시고
다시 받으세요.

</details>

### 2. 워치와 페어링

PC와 워치가 **같은 Wi-Fi**에 있어야 합니다 (워치가 LTE나 블루투스 경유면 안 됩니다).

1. **PC에서 먼저** `새 워치 연결 (페어링 열기)` — 120초 창이 열립니다
2. 워치에서 **Taptrol** 실행 → `🟢 PC 발견` 대기
   (브로드캐스트를 막는 공유기면 3초 후 서브넷 스캔으로 자동 전환됩니다)
3. 워치 `PC 연결하기 🔌` → 확인 코드가 표시됩니다
4. **PC 창의 코드와 워치 코드를 눈으로 대조** → 같으면 `코드 일치 — 요청 전송`
5. PC 승인 창에서 `예`

한 번 페어링하면 다음부터는 앱만 켜면 자동으로 연결됩니다.

## 보안

- 모든 통신은 **인증서 고정(certificate pinning)을 적용한 TLS 1.2+** 로 암호화됩니다
- PC는 ECDSA P-256 자체 서명 인증서로 자신을 증명하고, 사용자가 **확인 코드를 눈으로 대조**합니다
- 페어링 비밀키는 PC에서 **Windows DPAPI**, 워치에서 **Android KeyStore(AES-256-GCM)** 로 보호됩니다
- 세션마다 **HMAC-SHA256 상호 인증**을 거칩니다
- **개발자 서버가 존재하지 않습니다.** 데이터는 사용자의 기기와 로컬 네트워크를 벗어나지 않습니다

자세한 내용은 [PRIVACY.md](PRIVACY.md)를 참고하세요.
리시버에 포함된 오픈소스 구성요소는 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)에 있습니다.

## 문제 해결

**워치가 PC를 못 찾습니다**
- 방화벽에서 `TaptrolReceiver.exe`를 허용했는지 확인하세요 (8765/TCP, 8766/UDP)
- 워치가 Wi-Fi에 연결돼 있는지 확인하세요 (LTE·블루투스 경유로는 동작하지 않습니다)
- 공유기의 "AP isolation" 또는 "클라이언트 격리" 기능이 켜져 있으면 꺼야 합니다
- 게스트 Wi-Fi는 대부분 기기 간 통신을 막습니다

**연결됐다가 자꾸 끊깁니다**
- 워치 화면이 꺼져도 연결은 유지됩니다. 다만 배터리를 위해 **연결한 채 앱을 떠나면 10분 뒤**, **화면이 꺼진 채 30분간 조작이 없으면** 연결을 정리합니다. 앱을 다시 열면 자동으로 다시 연결됩니다
- 삼성 워치는 화면이 2분 넘게 꺼지면 켤 때 시계 화면으로 돌아갑니다. 발표 중이라면 Taptrol을 다시 여세요(연결은 그대로입니다)
- 워치를 들고 자리를 비웠다 돌아왔는데 재연결이 한참 걸리면 PC 리시버를 **9.9.8 이상**으로 업데이트하세요
- PC의 Wi-Fi가 절전 모드로 들어가지 않는지 확인하세요

**키 입력이 엉뚱한 곳으로 갑니다**
- 슬라이드 제어는 현재 포커스된 창으로 전달됩니다. PowerPoint 창을 활성화한 뒤 조작하세요
